> 맨 위 항목의 버전은 `plugin.json` 버전과 일치해야 하며, 위 링크는 안내 훅이 인쇄하는 링크와
> 일치해야 합니다 — 둘 다 `manifest-gate.ps1`이 검사합니다.

## v0.19.0 — 2026-08-05

- 플러그인이 이 머신에서 **처음 적용되는 세션**에도 한 줄 안내가 뜹니다: 적용된 버전과
  릴리스 노트 링크만(불릿 없음), 머신당 1회. 신규 설치자, 그리고 v0.18을 건너뛰고 바로
  이후 버전으로 온 경우가 여기에 해당합니다 (ADR 0031).
- 기존의 "vA → vB 업데이트됨" 안내는 그대로입니다 — 이전 버전이 기록된 머신에서만
  나옵니다.

## v0.18.0 — 2026-08-05

- 버전 업데이트 안내가 생겼습니다: 새 버전이 처음 로드된 세션 시작 시, 무엇이 바뀌었는지
  요약(이 파일의 해당 항목)과 릴리스 노트 탭 링크를 **버전당 한 번** 보여 줍니다. 이미 본
  버전에서는 침묵합니다.
- 마지막으로 안내한 버전을 `~/.claude/ywr-harness/announced-version` 한 줄 파일에
  기록합니다 — 플러그인이 사용자 스코프에 쓰는 유일한 파일입니다.
- 릴리스 노트 정본(이 파일)이 플러그인과 함께 배포되고, 온보딩 가이드에 릴리스 노트 탭이
  추가됐습니다. 자동 훅은 5종이 됩니다.

## v0.17.0 — 2026-08-05

- 세션 시작 시 git hooks 미배선 안내가 생겼습니다: 레포에 `.githooks/`가 있는데 이 클론의
  `core.hooksPath`가 설정돼 있지 않으면, 배선 한 줄 명령(`git config core.hooksPath
  .githooks`)을 제안합니다. **제안만** 하며 아무것도 자동으로 바꾸지 않습니다 (ADR 0029).
- 배선된 클론, `.githooks/`가 없는 레포, 다른 훅 경로를 쓰는 레포에서는 침묵합니다.

## v0.16.1 — 2026-08-04

- 배포 레포 README에 온보딩 가이드 링크가 실렸습니다 (claude.ai Team 좌석 로그인 필요 —
  README에 명시). 별도 공지 대신 이 링크가 상시 안내 경로입니다.

## v0.16.0 — 2026-08-04

- 리뷰 리추얼이 정리됐습니다: 적대 코드리뷰는 **슬라이스당 1회**이며, 확정 지적을 고친 수정
  diff는 두 번째 전체 리뷰가 아니라 게이트 재실행 + 지적별 수정 확인으로 마감합니다
  (ADR 0028). `ywr-harness:slice-close` 스킬과 리뷰 워크플로 안내문에 반영됐습니다.

## v0.15.0 — 2026-07-31

- 상태바 끝에 **이 머신에 설치된 플러그인 버전**(`ywr-harness vX.Y.Z`)이 표시됩니다. 자동
  업데이트로 디스크가 먼저 새 버전이 되므로, 세션과 디스크의 버전 차이가 곧 "재시작하면
  적용" 신호입니다 (ADR 0027).
- 기존에 상태바를 설치한 머신은 `install.ps1`을 다시 실행해야 새 세그먼트가 나옵니다.

## v0.14.0 — 2026-07-31

- `ywr-harness:verify`가 전용 verifier 에이전트로 실행됩니다 (sonnet · effort medium —
  A/B 측정으로 결정, ADR 0025). 절차 수행 검증 비용이 내려갑니다.
- 같은 날 관리 설정으로 마켓플레이스 **자동 업데이트가 켜졌습니다** (ADR 0026): 이후 버전은
  다음 세션 시작 후 몇 분 안에 자동 설치되며, `claude plugin update`를 직접 돌릴 필요가
  없습니다. 실행 중인 세션은 재시작해야 새 버전을 씁니다.

## v0.13.0 — 2026-07-29

- `.harness.json`에 **스크립트 게이트**를 선언할 수 있습니다: 레포 자체 게이트 스크립트를
  클로즈드-셋 러너 + 검증된 레포 경로로 선언하면 CI와 pre-commit이 실행합니다 (ADR 0024).
  자유 명령 문자열은 계속 거부됩니다.
- 게이트 명령 조합 경로의 인젝션 방어가 강화됐습니다 (적대적 파일명·`cwd`·빈 인자 목록 모두
  한 초크포인트에서 검증).

## v0.12.0 — 2026-07-27

  `claude plugin install ywr-harness@ywrlabs` — 자격증명 없이 익명 HTTPS로 받아집니다

  코드리뷰 워크플로, `/ywr-harness:harness-init` · `/ywr-harness:verify` ·
  `/ywr-harness:slice-close` 스킬, 상태바 설치기, worker/mech 에이전트.
