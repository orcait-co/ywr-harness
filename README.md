# ywr-harness (배포본)

`ywr-harness` Claude Code 플러그인의 **배포 전용 레포**입니다. 여기에는 플러그인 산출물만 들어
있고, 정본(canon)과 그 히스토리·결정 기록은 YWR Labs 가 별도로 보관합니다.

## 온보딩 가이드

처음이라면 **사내 온보딩 가이드**를 먼저 보세요 — 조직 지침 확인부터 플러그인 설치·사용법,
상태바, 문제 해결까지 단계별 성공/실패 신호와 함께 정리돼 있습니다:

> https://claude.ai/code/artifact/a4387fdf-63d1-4a3d-9c8e-c362c9215a54

이 링크는 claude.ai 페이지라서 **Team 좌석 계정으로 로그인**돼 있어야 열립니다 — 아래
전제조건의 "자격증명 필요 없음"은 플러그인 설치에 대한 이야기이고, 이 가이드 링크에는
해당하지 않습니다. 로그인했는데도 안 열리면 John에게 공유를 요청하세요.

## 설치

마켓플레이스 등록과 플러그인 설치는 모두 조직 관리 설정으로 **자동**입니다. 다음 세션이 백그라운드로
플러그인을 설치하고, 그다음 세션부터 로드됩니다. 입력할 명령은 없습니다. 조직 설정이 켜 두므로 각자 끄거나 제거할 수 없습니다.
측정된 것은 터미널의 대화형 세션입니다. Desktop 앱과 VS Code 에서의 자동 설치는 문서화돼 있지 않고,
Desktop 문서에 따르면 Desktop 앱의 WSL 세션은 플러그인을 로드하지 않습니다.

세션 시작 때 필요한 도구가 없다는 안내 줄이 뜨면 `/ywr-harness:setup` 을 입력하고, 설치가 끝나면
Claude Code 를 다시 시작하세요.

### 전제조건

- 접근 자격증명은 **필요 없습니다** — 이 레포는 public 이고 마켓플레이스는 익명 HTTPS 로
  받아집니다. GitHub 계정도 SSH 키도 필요 없습니다. (위 온보딩 가이드 링크만 예외 —
  claude.ai Team 좌석 로그인이 필요합니다.)
- `pwsh` 7 · `node` · `python` 3.9+ (게이트 스크립트와 훅이 씁니다)

### 등록이 안 된 것처럼 보일 때

마켓플레이스 등록은 세션 시작 시 **비동기로** 진행됩니다. 아주 짧게 끝나는 헤드리스 실행
(`claude -p "..."`)은 clone 이 끝나기 전에 종료해서 아무것도 등록하지 않습니다. 대화형 세션을
한 번 띄우면 해결됩니다. 플러그인 설치도 같습니다 — 헤드리스 실행은 설치를 백그라운드로 돌리므로,
첫 사용은 대화형 세션으로 하세요.

## 이 레포에 PR 을 보내지 마세요

**생성된 산출물**이라 다음 릴리스에서 통째로 덮어씁니다. 결함·요청은 PR 대신 세션에서
`/ywr-harness:feedback` 으로 보내 주세요 — 확인 한 번 뒤 이 레포의 이슈로 등록됩니다. 플러그인이
로드되지 않으면 johnkim@ywrlabs.com 으로 주세요. 수정은 정본에서 이뤄지고 버전으로 배포됩니다.

급하게 막혔다면 포크하지 말고 `/ywr-harness:feedback` 으로 알리거나 John 에게 연락하세요. 조직 설정에서
플러그인을 끄는 것이 정식 탈출구입니다.
